# Hand-Det（手部检测）

## 开发环境搭建

### Windos安装miniconda

- 直接访问[官网](https://anaconda.net.cn/download/success)下载安装

### Linux安装miniconda

```
wget https://repo.anaconda.com/miniconda/Miniconda3-latest-Linux-x86_64.sh
chmod 777 Miniconda3-latest-Linux-x86_64.sh
./Miniconda3-latest-Linux-x86_64.sh
export PATH="~/miniconda3/bin:$path"
```

### 配置conda

1. Windows开始菜单启动Anaconda Prompt，Linux直接在shell操作
2. 添加清华的镜像仓库：

```
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/free/
conda config --add channels https://mirrors.tuna.tsinghua.edu.cn/anaconda/pkgs/main/
conda config --set show_channel_urls true
```

3. 初始化

```
conda init
```

4. 删除虚拟环境的命令

```
conda env list
conda env remove --name HandDet
```

5. 创建虚拟环境

```
conda create -n HandDet -y python=3.12
```

6. 激活虚拟环境

```
conda activate HandDet
```

7. 安装包

```
pip install ultralytics
pip install onnx onnxslim onnxruntime-gpu
```

8. 退出虚拟环境

```
conda deactivate
```

9. PyCharm开发可选择项目的conda环境为HandDet

# Gesture-Recognition（手势识别）

## 开发环境搭建

- 参考Hand-Det

## 样本准备

### 公共数据集

1. 下载：[Light-HaGRID](https://opendatalab.com/sdf/Dataset)
2. 使用X-AnyLabeling生成yolo标签

- 分类文件：DataProcess/yolo_cls_Light-HaGRID.txt

3. 删除原始数据集里的json文件

- 使用DataProcess/deleteJson.py

4. 所有数据集放在同一个文件夹下

- 使用DataProcess/moveFile.py

5. 使用DataProcess/labels-18instead0.py进行类别修正，删除生成的no_gesture类别，将最后的two_up_inverted改为0

- 类别对应如下

```
0: two_up_inverted
1: call
2: dislike
3: fist
4: four
5: like
6: mute
7: ok
8: one
9: palm
10: peace
11: peace_inverted
12: rock
13: stop
14: stop_inverted
15: three
16: three2
17: two_up
```

6. 抽取yolo训练数据

- 使用DataProcess/yolov8GetTest.py抽取1%为测试数据（移动原数据，确保后面抽取的训练集和验证集不包含测试集）
- 使用DataProcess/yolov8GetVal.py抽取1%为验证数据（拷贝原数据）
- 使用DataProcess/yolov8GetTrain.py抽取99%为训练数据（抽取1%的数据移动后，剩下的原数据则为训练数据）

7. 按照yolov8格式存放数据

- Train\Light-HaGRID-YoloTrainData
- 使用DataProcess/getImagesName.py获取对应的txt

## 训练

1. 训练配置

- 数据集配置：coco8.yaml
- 类别如果不是递增，修改改ultralytics/cfg/default.yaml的classes
- 使用CUDA设备0和1：device=[0, 1]
- 使用cpu：device='cpu'
- 早停机制：fitness = 0.1 * mAP50 + 0.9 * mAP50-95，这个指标连续 patience 轮不涨，就停

2. 开始训练

```
python train_coco.py
```

3. 预测

```
python predict_pt.py
```

4. 使用测试集验证

```
python val_test.py
```

5. 导出onnx，并使用onnx预测

```
python export2onnx.py
python predict_onnx.py
```
